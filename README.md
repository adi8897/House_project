# הבית שלנו

אתר לניהול התקציב של פרויקט בניית הבית בניר דוד — הוצאות בפועל, הוצאות צפויות, הון וחסכונות,
ניתוח משכנתא והמלצות ליעדים כספיים.

כל הנתונים נשמרים בדפדפן המקומי בלבד (localStorage לנתונים, IndexedDB לקבלות). שום דבר לא עולה
לשרת ולא נשמר ב-git.

## הרצה

```bash
npm install
npm run dev      # פיתוח, http://localhost:5173
npm run build    # בניה לפרודקשן לתיקיית dist/
npm run preview  # תצוגה מקדימה של הבילד
```

## מבנה

| נתיב | תוכן |
|---|---|
| `src/data/seed.ts` | נתוני הפתיחה — 8 קטגוריות התקציב, שורות המשנה, ההוצאות, מקורות ההון |
| `src/lib/selectors.ts` | חישובי הצבירה: עלות כוללת, הון נזיל, משכנתא נדרשת, רזרבה |
| `src/lib/mortgage.ts` | לוח שפיצר, תמהיל, מגבלות בנק ישראל, מיטוב תמהיל ותקופה |
| `src/lib/advice.ts` | מנוע ההמלצות ושלושת תרחישי ה״נמוך ביותר״ |
| `src/lib/receipts.ts` | אחסון הקבלות ב-IndexedDB |
| `src/pages/` | שמונה המסכים |

## מקורות הנתונים

הנתונים נלקחו משני קבצים: חוברת התקציב של היועצים הכלכליים, וקובץ המעקב הקצר. במקום שבו השניים
חלוקים (יתרות, חיסכון חודשי) נטענו הערכים מחוברת התקציב, והפער מוצג במסך ״הון וחסכונות״ עם כפתור
להחלפה.

מספרי מפתח שמתאמתים מול החוברת:

- סה״כ רף המעבר — 2,739,979 ₪
- הון נזיל לתהליך — 993,356 ₪ (יתרות היום + 36 חודשי חיסכון)
- משכנתא נדרשת — 1,288,358 ₪
- יכולת החזר מקסימלית — 16,345 ₪ (חיסכון פוטנציאלי + שכר הדירה שנחסך במעבר)

## הערה על התאמות

- **תשתיות** — החוברת מפרטת 310,000 ₪ + 15,000 ₪ אך מסכמת 300,000 ₪. נוספה שורת התאמה של
  ‎-25,000 ₪ כדי לשמור על הסה״כ.
- **ריביות המשכנתא** — הנחות עבודה בלבד, ניתנות לעריכה במסך המשכנתא. יש לעדכן לפי הצעות אמיתיות
  מהבנקים.

## צבעים ונגישות

סדר הצבעים הקטגוריאלי ב-`src/styles.css` עבר אימות מול בודק הנגישות של מדריך הויזואליזציה, במצב
בהיר ובמצב כהה. שינוי הסדר או הגוונים מחייב הרצה חוזרת של הבודק.
