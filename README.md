# הבית שלנו

אתר לניהול התקציב של פרויקט בניית הבית בניר דוד — הוצאות בפועל, הוצאות צפויות, הון וחסכונות,
ניתוח משכנתא והמלצות ליעדים כספיים.

כל הנתונים נשמרים בדפדפן המקומי בלבד (localStorage לנתונים, IndexedDB לקבלות). שום דבר לא עולה
לשרת ולא נשמר ב-git.

## הרצה

```bash
npm install
npm run dev      # פיתוח, http://localhost:5173
npm run build    # בניה לפרודקשן לתיקיית dist/
npm run preview  # תצוגה מקדימה של הבילד
```

## מקורות הנתונים

הנתונים נלקחו משני קבצים: חוברת התקציב של היועצים הכלכליים, וקובץ המעקב הקצר. במקום שבו השניים
חלוקים (יתרות, חיסכון חודשי) נטענו הערכים מחוברת התקציב, והפער מוצג במסך ״הון וחסכונות״ עם כפתור
להחלפה.

מספרי מפתח שמתאמתים מול החוברת:

- סה״כ רף המעבר — 2,739,979 ₪
- הוצאנו עד היום — 533,265 ₪
- הון נזיל לתהליך — 1,249,427 ₪ (יתרות היום + 36 חודשי חיסכון)
- משכנתא נדרשת — 957,287 ₪
- יכולת החזר מקסימלית — 16,345 ₪ (חיסכון פוטנציאלי + שכר הדירה שנחסך במעבר)
- רזרבה — 329,475 ₪

## שורות מחושבות

שתי שורות תקציב אינן ניתנות לעריכה ישירה, כי החוברת מחשבת אותן:

- **בניה** = `(גודל הבית + 40% × מרפסת) × מחיר למ״ר` = `(145 + 0.4×30) × 10,620` = 1,667,340 ₪.
  הבית עצמו הוא 145 מ״ר; המרפסת מתומחרת ב-40% מהתעריף. נשלט ממסך התקציב.
- **רזרבה** = 15% מהיתרה להוצאה של מגרש, תשתיות, אגרות, בעלי מקצוע, הלבשות ובניה. היא מתכווצת
  ככל שמשלמים, ואינה נכללת בסה״כ עלות הפרויקט.

## הערה על התאמות

- **תשתיות** — החוברת מפרטת 310,000 ₪ + 15,000 ₪ אך מסכמת 300,000 ₪. נוספה שורת התאמה של
  ‎-25,000 ₪ כדי לשמור על הסה״כ.
- **בעלי מקצוע בחריגה** — שולמו 155,600 ₪ מול תקציב 123,000 ₪, כי שורת ״עיצוב פנים״ נשארה 0
  בחוברת בעוד שכבר שולמו 75,000 ₪ למעצבת. האתר מסמן את החריגה; ההחלטה אם להעלות את התקציב או
  לקזז היא שלכם.
- **ריביות המשכנתא** — הנחות עבודה בלבד, ניתנות לעריכה במסך המשכנתא. לכן ״משכנתא אפשרית״ באתר
  שונה מעט מהחוברת (1,541,609 ₪ מול 1,496,063 ₪) — החוברת מניחה ריבית מעט גבוהה יותר. ה״משכנתא
  הנדרשת״, שהיא המספר שקובע, מתאמת בדיוק.

## צבעים ונגישות

סדר הצבעים הקטגוריאלי ב-`src/styles.css` עבר אימות מול בודק הנגישות של מדריך הויזואליזציה, במצב
בהיר ובמצב כהה. שינוי הסדר או הגוונים מחייב הרצה חוזרת של הבודק.
